# CloudOps Core API

Backend microservice for **CloudOps Lab**, built with Node.js, Express, Docker, and Docker Compose.

This service represents the core API of the CloudOps Lab platform and is part of a practical DevOps/cloud architecture project focused on containers, environment configuration, health checks, and basic observability.

---

## Tech Stack

- Node.js
- Express.js
- Docker
- Docker Compose
